# Авито · Вопросы для бизнеса

Интерактивная презентация с девятью вопросами: три категории × три уровня сложности.

![Превью интерактивной презентации](docs/preview.jpg)

## Использование

- Нажмите карточку, чтобы открыть вопрос.
- «Ответили · к вопросам» ставит отметку и возвращает на поле.
- «К вопросам» и Escape возвращают без изменения статуса.
- Отвеченную карточку можно открыть повторно и снять отметку.
- «Начать заново» сбрасывает прогресс после подтверждения.
- Кнопка «На весь экран» или F включает режим презентации, если браузер его поддерживает.

Отметки сохраняются в localStorage конкретного браузера и синхронизируются между его вкладками. Между разными устройствами прогресс не переносится. В приватном режиме сохранение зависит от настроек браузера. Сервер, аналитика и внешние библиотеки не используются.

## Запуск

Статический HTML/CSS/JavaScript, без сборки и зависимостей:

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173. GitHub Pages публикует корень ветки `main`.

## Редактирование

Все вопросы и категории находятся в `app.js`, в массиве `categories`. Идентификаторы определяют сохранённый прогресс; при замене состава вопросов измените версию `storageKey`.

## Фирменные материалы

Источник: [Avito Goods Guides B2B · Sellers](https://www.figma.com/design/imlZbLHwQBBW8BTUH3dFLX/?node-id=16289-722).

- Белая основа #FFFFFF, основной текст #000000. Тёмно-зелёный #003914 используется для графики внутри зелёных UI-элементов.
- UI-плашки и круги: фирменный зелёный #04E061, тёмные иконки. См. [построение UI-элементов](https://www.figma.com/design/imlZbLHwQBBW8BTUH3dFLX/?node-id=16289-1587) и [образцы UI](https://www.figma.com/design/imlZbLHwQBBW8BTUH3dFLX/?node-id=16289-42487).
- Основные карточки белые. Зелёный занимает небольшие области, чтобы сохранить светлый спокойный визуал без подмены фирменного оттенка. Отвеченные карточки получают 8% тон фирменного зелёного; нейтральные серые используются для границ и вторичного текста.
- Дополнительная палитра графики #C9FFBF / #FEEADB / #F7C1C5 не используется для заливок UI. [Палитра и роли цветов](https://www.figma.com/design/imlZbLHwQBBW8BTUH3dFLX/?node-id=16289-41062), [тональные градации UI](https://www.figma.com/design/imlZbLHwQBBW8BTUH3dFLX/?node-id=16289-39129).
- Уровни различаются названиями и 1–3 полосками вместо светофорной заливки. В брифе разрешена альтернативная визуализация сложности.
- Начертания: Medium для заголовков, Bold для кнопок и плашек, Regular для остального текста. Повторные подсказки и счётчики уровней убраны.
- Оригинальный логотип экспортирован из узла 16289:883.
- CoFo Avito Display Regular, Medium и Bold взяты из предоставленного пользователем набора фирменных шрифтов. Фирменные материалы принадлежат правообладателю и включены для этого проекта, без отдельной открытой лицензии.

Тексты девяти вопросов сохранены без изменений. Уровень обозначен названием и количеством полосок, отметка ответа — галочкой и текстом.
