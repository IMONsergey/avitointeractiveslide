# Авито · Предпринимательский блиц

Интерактивная презентация с девятью вопросами: три категории × три уровня сложности.

![Превью интерактивной презентации](docs/preview.jpg)

## Использование

- На поле вопросов нажмите цифру `1`–`9`: соответствующая карточка откроется без мыши.
- Нумерация идёт по визуальным рядам слева направо: `1–3`, `4–6`, `7–9`.
- Вопрос считается отвеченным сразу после открытия; карточка становится серой и получает галочку.
- Нажмите `Escape`, чтобы вернуться к полю вопросов.
- Внутри вопроса нет кнопок и дополнительных действий.
- `F` включает или выключает полноэкранный режим, если браузер его поддерживает.
- «Начать заново» в шапке по-прежнему сбрасывает весь прогресс после подтверждения.

Отметки сохраняются в localStorage конкретного браузера и синхронизируются между его вкладками. Между разными устройствами прогресс не переносится. В приватном режиме сохранение зависит от настроек браузера. Сервер, аналитика и внешние библиотеки не используются.

## Запуск

Статический HTML/CSS/JavaScript, без сборки и зависимостей:

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173. GitHub Pages публикует корень ветки `main`.

## Редактирование

Все вопросы и категории находятся в `app.js`, в массиве `categories`. Идентификаторы определяют сохранённый прогресс; при замене состава вопросов измените версию `storageKey`.

- Светлая версия по присланным клиентом правкам от 26.09.2026: белая основа, чёрный текст, пастельные зелёный #D8FCDE, жёлтый #FDF3B5 и розовый #FDC8D2. Заливки взяты из актуального клиентского образца; это адаптация под правки, а не новые цвета брендбука.
- В шапке: «Предпринимательский блиц: как не платить за ошибки в продажах».
- На начальном экране карточка содержит уровень сложности и рабочий номер `1–9`; номер используется как клавиатурная команда открытия вопроса. Тексты самих вопросов и крупные декоративные номера категорий не показываются.
- Отвеченная карточка становится светло-серой #E9E9EB, стрелка заменяется галочкой. Статус дополнительно доступен скринридерам.
- На раскрытом слайде остаются только сам вопрос и текстовая подсказка `Esc · К вопросам`; кнопок внутри вопроса нет. Отметка ставится автоматически при открытии.
- CoFo Avito Display: Medium для заголовков, Bold для названий уровней и кнопок, Regular для уточняющей части вопроса.
- Оригинальный логотип экспортирован из узла 16289:883.
- CoFo Avito Display Regular, Medium и Bold взяты из предоставленного пользователем набора фирменных шрифтов. Фирменные материалы принадлежат правообладателю и включены для этого проекта, без отдельной открытой лицензии.

Тексты девяти вопросов сохранены без изменений и проверены на «ё». В названиях категорий исправлены «счёт» и «ушёл». Уровень обозначен цветом и названием, отметка ответа — светло-серой заливкой и галочкой.
